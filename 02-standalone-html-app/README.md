# 🌐 02 - Standalone Single-File Web Application
### Al Mustafa Heights Building Maintenance System (Portable Edition)

---

## 📖 Overview
This folder contains the **Zero-Dependency, Portable, Offline Single-File Web Application** for the Al Mustafa Heights building maintenance system.

It is designed to run directly inside any modern web browser without needing Node.js, npm packages, web servers, or internet access.

---

## 🚀 How to Run
1. Double-click **`index.html`** or right-click and choose **Open with Google Chrome / Microsoft Edge / Firefox / Brave**.
2. That's it! The complete UI runs locally in your browser.

---

## 🌟 Key Features
- **Zero Dependencies**: Entire JavaScript logic, Tailwind CSS, Lucide-style SVG icons, and HTML structures are contained inside this single file.
- **Offline Data Storage**: Uses browser `localStorage` to save, update, and manage monthly maintenance registers and expenses.
- **Urdu & Roman Support**: Bilingual labels for residents, heads of accounts, and financial reports.
- **Monthly Maintenance Ledger**: Auto-calculates monthly dues, paid amounts, prior arrears, total balance, and building cash-in-hand.
- **WhatsApp Message Generator**: Generates formatted Urdu WhatsApp broadcast notices for pending defaulters and paid confirmations.
- **Print & PDF Friendly**: Built-in CSS `@media print` rules for clean single-page printing and browser PDF saving.
